# رفوف — مكتبتك أقرب 📚

واجهة متجر كتب عربية بسيطة وسريعة، مصممة باتجاه RTL وبلهجة تونسية. تتضمن تصفح التصنيفات، البحث، المفضلة، سلة مشتريات محفوظة في المتصفح، ورسالة اشتراك تجريبية.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم ملفات ثابتة. لا تحتاج إلى تثبيت حزم أو إعداد build.

## الملفات

- `index.html` — بنية المتجر.
- `styles.css` — التصميم المتجاوب.
- `app.js` — بيانات الكتب والبحث والتصنيفات والسلة.

> المتجر واجهة تجريبية؛ إتمام الدفع والاشتراك غير مربوطين بخدمات خلفية بعد.
